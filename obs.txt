Personal Finance Control System (PFCS) - Documentação do Projeto

Este projeto é um sistema de controle financeiro pessoal desenvolvido com Django (Python) no backend e Tailwind CSS no frontend. Abaixo está a explicação de como cada parte funciona:

1. Banco de Dados (Models)
Localizado em financeiro/core/models.py, define a estrutura da tabela Transacao:
- titulo: Nome da transação (Ex: Mercado).
- valor: Valor numérico.
- tipo: 'R' para Receita (Ganhos) ou 'D' para Despesa (Gastos).
- data: Gravada automaticamente no momento da criação.
- observacoes: Campo opcional para detalhes adicionais.

2. Lógica do Sistema (Views)
Localizada em financeiro/core/views.py, controla as ações do usuário:

- Home (Página Inicial): 
  - Recupera todas as transações do banco.
  - Calcula o saldo total, o total de receitas e o total de despesas.
  - Envia esses dados para o template home.html.

- Adicionar:
  - Recebe os dados do formulário (titulo, valor, tipo, observacoes).
  - Cria um novo registro no banco de dados.
  - Redireciona o usuário de volta para a página inicial.

- Deletar:
  - Localiza uma transação pelo seu ID único e a remove do banco.

- Zerar Tudo:
  - Apaga todos os registros da tabela de transações de uma vez.

- Exportar (Excel):
  - Usa a biblioteca pandas para transformar os dados do banco em uma planilha.
  - Adiciona uma coluna de data, formata os valores e inclui uma linha de saldo final com um espaço de separação.

3. Interface Visual (Templates)
Localizada em financeiro/core/templates/:

- home.html:
  - Exibe o saldo principal em destaque.
  - Lista as transações de forma interativa.
  - Modal de Detalhes: Ao clicar em uma transação, um script JavaScript abre uma janela flutuante exibindo todas as informações, incluindo as observações.
  - Busca: Inclui uma barra de pesquisa para filtrar transações instantaneamente.

- adicionar.html:
  - Formulário para entrada de novos dados.
  - CSS Customizado: Foram aplicadas regras para esconder as setas (spinners) do campo de valor e estilizar os campos com o tema escuro.

4. Estilização (Tailwind & CSS)
- O projeto utiliza Tailwind CSS para um design moderno e responsivo (funciona bem no celular e no computador).
- O tema é focado em Dark Mode (fundo escuro) com cartões em estilo "Glassmorphism" (efeito de vidro).
